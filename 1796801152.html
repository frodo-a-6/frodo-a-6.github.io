KY-034 7-Farben Flash-LED

Wird dieses Modul mit Spannung versorgt, so wird automatisch eine Abfolge von Farbwechseln von der LED ausgestrahlt

Dieses Modul enthält eine 7-Farben-Flash-LED, die automatisch eine Abfolge von Farbwechseln ausstrahlt, sobald es mit Spannung versorgt wird. Die LED verfügt über 7 verschiedene Farben und kann alle daraus resultierenden Mischfarben erzeugen. Dieses Modul ist ideal für dekorative Beleuchtungsprojekte, visuelle Anzeigen und Effekte, bei denen wechselnde Farben gewünscht sind. Durch die automatische Farbabfolge benötigst du keine zusätzliche Steuerung, was die Integration in verschiedene Projekte erleichtert. Es eignet sich perfekt für kreative Anwendungen, bei denen eine dynamische und ansprechende Beleuchtung erforderlich ist.

Weihnachtsidee zum Bauteil

Weihnachtsidee: Die Christbaumspitze

Die 7-Farben-LED wird zum funkelnden Stern auf der Baumspitze. Die LED wechselt ihre Farben von allein; der Sketch schaltet sie mal länger, mal kürzer ein und lässt sie zwischendurch kurz verlöschen.

Verdrahtung

Wie im Abschnitt zum Bauteil oben: Signal an Pin 13, GND an GND.

Ablauf

Jede Leuchtphase dauert zufällig zwischen 2 und 6 Sekunden, die Pause zwischen 0,3 und 1,5 Sekunden. Der Serielle Monitor zählt die Runden mit. Weil die LED ihr Farbprogramm bei jedem Einschalten neu startet, sieht jede Runde ein wenig anders aus. Ein Tipp für die Optik: Stülpe einen Stern aus Transparentpapier über die LED.

Code-Beispiel

Diese Codebeispiel zeigt auf, wie eine LED mittels eines definierbaren Ausgangspins abwechselnd für vier Sekunden ein- und danach für zwei Sekunden ausgeschaltet werden kann.

Um das folgende Codebeispiel auf deinen Arduino zu laden, empfehlen wir die Verwendung der Arduino IDE. In der IDE kannst du den passenden Port und das richtige Board für dein Gerät auswählen.

Kopiere den unten stehenden Code in deine IDE. Um den Code auf deinen Arduino hochzuladen, klicke einfach auf den Upload-Button.

int led = 13; // Deklaration des LED-Eingangspin

void setup() {
  pinMode(led, OUTPUT); // Initialisierung Ausgangspin für die LED
}

void loop() {
  digitalWrite(led, HIGH); // LED wird eingeschaltet
  delay(4000); // Warte für 4 Sekunden
  digitalWrite(led, LOW); // LED wird ausgeschaltet
  delay(2000); // Warte für weitere zwei Sekunden
}

  Tuerchen 8: Tannengruen und Kerzenrot

const int led_red = 11;    // PWM-fähig
const int led_green = 10;  // PWM-fähig
const int SCHRITT_MS = 10; // Pause je Helligkeitsstufe: 256 Stufen = gut 2,5 s pro Übergang

void ueberblenden(int vonPin, int nachPin) {
  for (int i = 0; i <= 255; i++) {
    analogWrite(vonPin, 255 - i);
    analogWrite(nachPin, i);
    delay(SCHRITT_MS);
  }
}

void setup() {
  pinMode(led_red, OUTPUT);
  pinMode(led_green, OUTPUT);
  Serial.begin(9600);
  Serial.println((const __FlashStringHelper*)ART);
}

void loop() {
  Serial.println("Kerzenrot ...");
  ueberblenden(led_green, led_red);
  delay(1000);
  Serial.println("... Tannengrün ...");
  ueberblenden(led_red, led_green);
  delay(1000);
}

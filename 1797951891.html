Der Wichtel-Dolmetscher für Logikpegel

Auch Wichtel sprechen verschiedene Sprachen: Der Level Shifter übersetzt zwischen 3,3 V und 5 V.

Heute im Säckchen

KY-051 Voltage Translator / Level Shifter

Dieser Level-Shifter wandelt digitale Signale von einer Spannung in eine andere herunter bzw. herauf.

Der Voltage Translator oder Level Shifter wandelt digitale Signale von einer Spannung in eine andere um, entweder herauf oder herunter. Dieses Modul bietet insgesamt vier Kanäle, auf denen die Spannungsumwandlungen vorgenommen werden können.

In der heutigen Zeit arbeiten Mikrocontrollersysteme in verschiedenen Spannungsbereichen. Ältere Systeme wie Arduino, die auf einem Atmega-Controller basieren, nutzen 5V-Signale. Neuere Geräte wie der Raspberry Pi, der auf einem ARM-Controller basiert, arbeiten hingegen mit 3,3V-Signalen.

Wenn eine Kommunikation zwischen zwei Systemen mit unterschiedlichen Spannungspegeln erforderlich ist, muss das Spannungslevel angepasst, also "geshiftet", werden. Ohne diese Anpassung könnte die überschüssige Spannung zu Schäden an den empfindlicheren, niedrigspannigen Geräten führen.

Der Level Shifter ermöglicht eine sichere und effiziente Kommunikation zwischen Geräten mit unterschiedlichen Spannungsanforderungen und schützt so die Hardware vor potenziellen Schäden durch nicht kompatible Spannungspegel. Dies ist besonders wichtig in Projekten, die verschiedene Mikrocontroller und Sensoren integrieren, um eine reibungslose und sichere Funktion zu gewährleisten.

Pin-Belegung

Die Pin-Belegung ist auf der Modulplatine aufgedruckt.

Die Signale an den Ein-/Ausgängen A1-A4, sowie B1-B4 werden auf das jeweilige Spannungslevel geshiftet (VCCa -> A1-A4 | VCCb -> B1-B4)

Beispiel:

*Arduino Ausgang -> Digital [EIN] = 5 V @ B1 >>>>>>> 3.3 V @ A1 -> Raspberry Pi Eingang*

Eine zusätzliche Software bzw. Code wird nicht zum Betrieb benötigt; das Modul arbeitet autonom.

Bitte beachte, dass VCCb größer/gleich VCCa (Beispiel VCCb=5 V - VCCa=3,3 V) sein muss

Beispiel Anschluss-Belegung zwischen Arduino und Raspberry Pi:

ArduinoSensor
5 VVccb
Pin 3B1
Pin 4B2
Pin 5B3
Pin 6B4
GNDGND

Weihnachtsidee zum Bauteil

Weihnachtsidee: Der Wichtel-Dolmetscher

Der Arduino Uno arbeitet mit 5 V, viele andere Bausteine nur mit 3,3 V. Der Level Shifter übersetzt zwischen beiden wie ein Wichtel-Dolmetscher. Zur Probe morst der Arduino „FROHES FEST“ mit 5 V in die eine Seite hinein und misst auf der anderen Seite nach, mit welcher Spannung die Botschaft ankommt.

Verdrahtung

Ohne Raspberry Pi übernimmt der 3,3-V-Pin des Arduino die Niederspannungsseite:

ArduinoLevel Shifter
5VVccb
3.3VVcca
Pin 3B1
A0A1
GNDGND

Wie im Artikel beschrieben muss Vccb mindestens so groß sein wie Vcca, und beide Seiten brauchen gemeinsames GND. OE muss nicht angeschlossen werden.

Ablauf

Der Sketch morst die Botschaft mit den üblichen Längen: Punkt eine Einheit, Strich drei, Pause zwischen Buchstaben drei und zwischen Wörtern sieben Einheiten. Der Serielle Monitor schreibt Buchstabe und Morsecode mit. Nach jedem Durchgang zeigt er die höchste Spannung, die an A1 gemessen wurde: etwa 3,3 V statt 5 V.

const int PUNKT_MS = 200;  // Länge eines Morse-Punkts

// Morsecode für A bis Z

  ".-", "-...", "-.-.", "-..", ".", "..-.", "--.", "....", "..", ".---", "-.-", ".-..", "--",
  "-.", "---", ".--.", "--.-", ".-.", "...", "-", "..-", "...-", ".--", "-..-", "-.--", "--.."

float hoechsteSpannung = 0;

void morseElement(int einheiten) {
  digitalWrite(SIGNAL_B1, HIGH);
  delay(PUNKT_MS / 2);
  // Während das Signal anliegt: Was kommt auf der 3,3-V-Seite an?
  float volt = analogRead(MESS_A1) * (5.0 / 1023.0);
  hoechsteSpannung = max(hoechsteSpannung, volt);
  delay(einheiten * PUNKT_MS - PUNKT_MS / 2);
  digitalWrite(SIGNAL_B1, LOW);
  delay(PUNKT_MS);  // Pause innerhalb eines Buchstabens
}

// Auflösung zu Türchen 21: Der Aufregungsmesser
// Verdrahtung wie im Artikel KY-039 (Signal an A0)

const char ART[] PROGMEM = R"ART(
     *****     *****
   ********* *********
   *******************
    *****************
      *************
        *********
          *****
            *
  Tuerchen 21: Der Aufregungsmesser
)ART";

const int ledPin = 13;
const int analogPin = 0;
const int delayMsec = 60;

// Spitzenerkennung wie im Artikel: Ein Herzschlag ist der Beginn eines neuen Maximums
bool heartbeatDetected(int pin, int delay) {
  static int maxValue = 0;
  static bool isPeak = false;
  bool result = false;

  int rawValue = analogRead(pin);
  rawValue *= (1000 / delay);

  // Grundlinie zurücksetzen, wenn der Finger entfernt wurde
  if (rawValue * 4L < maxValue) {
    maxValue = rawValue * 0.8;
  }
  if (rawValue > maxValue - (1000 / delay)) {
    if (rawValue > maxValue) {
      maxValue = rawValue;
    }
    if (!isPeak) {
      result = true;
    }
    isPeak = true;
  } else if (rawValue < maxValue - (3000 / delay)) {
    isPeak = false;
    maxValue -= (1000 / delay);
  }
  return result;
}

const char* aufregung(int bpm) {
  if (bpm < 70) return "Ganz entspannt, wie nach dem Festessen.";
  if (bpm < 90) return "Leichte Vorfreude liegt in der Luft.";
  if (bpm < 110) return "Bescherungsfieber! Ist das Glöckchen schon zu hören?";
  return "Gleich platzt das Geschenkpapier vor Aufregung!";
}

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
  Serial.println((const __FlashStringHelper*)ART);
  Serial.println("Finger ruhig auf den Sensor legen und nicht wackeln.");
}

void loop() {
  static int beatMsec = 0;
  if (heartbeatDetected(analogPin, delayMsec)) {
    int heartRateBPM = beatMsec > 0 ? 60000L / beatMsec : 0;
    digitalWrite(ledPin, HIGH);
    // Unplausible Werte (z. B. beim Auflegen des Fingers) überspringen
    if (heartRateBPM > 30 && heartRateBPM < 200) {
      Serial.print("Puls ");
      Serial.print(heartRateBPM);
      Serial.print(": ");
      Serial.println(aufregung(heartRateBPM));
    }
    beatMsec = 0;
  } else {
    digitalWrite(ledPin, LOW);
  }
  delay(delayMsec);
  beatMsec += delayMsec;
}

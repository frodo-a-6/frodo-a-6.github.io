Der Magnet unterm Tannenbaum

Unter dem Tannenbaum liegt ein Magnet versteckt? Der analoge Reed-Sensor findet ihn.

Heute im Säckchen

KY-025 Analoger Reed-Magnetsensor

Wird ein Magnetfeld detektiert, so wird dies am digitalen Ausgang ausgegeben.

Dieses Modul enthält einen analogen Reed-Magnetsensor, der ein Magnetfeld erkennt und diese Information an den digitalen Ausgang weiterleitet. Reedkontakte bestehen aus zwei dünnen Kontaktfedern in einer Glasröhre, die sich bei Anwesenheit eines Magnetfeldes aufeinander zubewegen. Dadurch wird ein elektrischer Kontakt geschlossen und das Signal durchgeschaltet.

Wenn der Sensor ein Magnetfeld detektiert, schließt er den Kontakt und gibt ein digitales Signal aus. Dies macht den Reed-Magnetsensor ideal für Anwendungen, bei denen die Anwesenheit eines Magneten erkannt werden muss, wie z.B. in Tür- und Fensteralarmen, Positionssensoren oder anderen Sicherheits- und Überwachungssystemen. Die einfache Funktionsweise und Zuverlässigkeit des Reed-Magnetsensors machen ihn zu einer nützlichen Komponente für viele Projekte, bei denen Magnetfelder detektiert werden sollen.

Benutzungshinweis

Dieser Sensor ist ideal für die Schwellenwertmessung geeignet. Das bedeutet, dass der Sensor ein digitales High-Signal abgibt, sobald ein am Drehpotentiometer vom Anwender eingestellter Schwellenwert überschritten wird. Hierbei ist zu beachten, dass das digitale Signal aus dem Vergleich des Wertes, welche am Drehpotentiometer eingestellt ist und dem gemessenen Wert am Sensor ist, welche dann vom auf dem Board verbauten LM393 Komparator verglichen werden. Dabei ist der eingestellte Wert des Drehpotentiometers der Schwellenwert, welcher dazu dient ein logisches High-Signal zu definieren.

Digitaler Ausgang: Wird ein Magnetfeld erkannt, so wird hier ein Signal ausgegeben

Analoger Ausgang: Direkter Messwert der Sensoreinheit

LED1: Zeigt an, dass der Sensor mit Spannung versorgt ist

LED2: Zeigt an, dass ein Magnetfeld detektiert wurde

Funktionsweise des Sensors

Dieser Sensor besitzt auf seiner Platine zwei funktionelle Bestandteile: Die vordere Sensoreinheit, welche das Umfeld physikalisch misst und als analoges Signal auf die zweite Einheit, den Komparator, ausgibt. Der Komparator vergleicht den Messwert des Sensors mit der am Drehpotentiometer eingestelltem Wert und gibt bei Überschreitung des Wertes am Drehpotentiometer ein logisches High-Signal am digitalen Pin und der LED L1 aus.

Hierbei ist zu beachten: Das Signal ist invertiert. Wird ein hoher Wert gemessen, so resultiert dies in einem niedrigeren Spannungswert am analogen Ausgang.

Weihnachtsidee zum Bauteil

Weihnachtsidee: Das geheime Geschenkversteck

Ein Magnet wird zum Zauberschlüssel: Nur wer ihn zwei Sekunden lang an den Reed-Sensor hält, öffnet das geheime Geschenkversteck. Wird der Magnet zu früh weggenommen, bleibt es zu. Ein Fortschrittsbalken zeigt, wie weit das Aufschließen schon ist.

Verdrahtung

Wie im Abschnitt zum Bauteil oben: Analoges Signal an A0, digitales Signal an Pin 3, +V an 5V, GND an GND.

Ablauf

Der Digitalausgang meldet den Magneten, der Analogwert erscheint zur Kontrolle neben dem Balken. Ab welcher Nähe der Magnet zählt, stellst du am Poti des Moduls ein. Die Haltezeit änderst du mit HALTEZEIT.

Code-Beispiel

Das Programm liest den aktuellen Spannungswert aus, der am analogen Ausgang gemessen werden kann, und gibt diesen über die serielle Schnittstelle aus. Zudem wird ebenfalls der Zustand des digitalen Pins in der Konsole angegeben. Dieser gibt an, ob der Grenzwert überschritten wurde.

Um das folgende Codebeispiel auf deinen Arduino zu laden, empfehlen wir die Verwendung der Arduino IDE. In der IDE kannst du den passenden Port und das richtige Board für dein Gerät auswählen.

Kopiere den unten stehenden Code in deine IDE. Um den Code auf deinen Arduino hochzuladen, klicke einfach auf den Upload-Button.

// Deklaration und Initialisierung der Eingang-Pins
int analog_input = A0; // Analoger Ausgang des Sensors
int digital_input = 3; // Digitaler Ausgang des Sensors

void setup () {
  pinMode(analog_input, INPUT);
  pinMode(digital_input, INPUT);
  Serial.begin(9600); // Serielle Ausgabe mit 9600 bps
  Serial.println("KY-025 Magnetfelderkennung");
}

// Das Programm liest die aktuellen Werte der Eingang-Pins
// und gibt diese auf der seriellen Ausgabe aus
void loop () {
  float analog_value;
  int digital_value;

  //Aktuelle Werte werden ausgelesen, auf den Spannungswert konvertiert...
  analog_value = analogRead(analog_input) * (5.0 / 1023.0);
  digital_value = digitalRead(digital_input);

  //... und an dieser Stelle ausgegeben
  Serial.print("Analoger Spannungswert: ");
  Serial.print(analog_value, 4);
  Serial.print(" V, \t Grenzwert: ");

  if (digital_value == 1) {
      Serial.println("erreicht");
  }
  else {
      Serial.println("noch nicht erreicht");
  }
  Serial.println("----------------------------------------------------------------");
  delay(1000);
}

const char ART[] PROGMEM = R"ART(
    *    .    *    .    *
   ||           ||
    \\           \\
     ||           ||

   ||           ||
  Tuerchen 16: Den Schlittenspuren folgen
)ART";

const int linetracking = 10;          // KY-033, HIGH = Linie erkannt
const unsigned long VERLOREN_MS = 1000;
bool aufSpurVorher = false;
bool verlorenGemeldet = true;         // zu Beginn liegt noch keine Spur unter dem Sensor
unsigned long abgekommen = 0;

void setup() {
  pinMode(linetracking, INPUT);
  digitalWrite(linetracking, HIGH);  // interner Pull-up wie im Artikel
  Serial.begin(9600);
  Serial.println((const __FlashStringHelper*)ART);
  Serial.println("Führe den Sensor über eine dunkle Spur auf hellem Papier.");
}

void loop() {
  bool aufSpur = digitalRead(linetracking) == HIGH;

  if (aufSpur && !aufSpurVorher) {
    Serial.println("Schlittenspur gefunden. Immer der Spur nach!");
    verlorenGemeldet = false;
  } else if (!aufSpur && aufSpurVorher) {
    abgekommen = millis();
  }

  // Kurze Lücken sind normal; erst nach einer Sekunde ist die Spur wirklich verloren
  if (!aufSpur && !verlorenGemeldet && millis() - abgekommen > VERLOREN_MS) {
    Serial.println("Vom Weg abgekommen! Der Schlitten steckt im Tiefschnee.");
    verlorenGemeldet = true;
  }
  aufSpurVorher = aufSpur;
  delay(20);
}

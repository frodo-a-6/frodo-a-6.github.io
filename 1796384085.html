Heute im Säckchen

KY-028 Temperatursensor (Thermistor)

Dieses Modul beinhaltet einen NTC Thermistor welcher Temperaturen im Bereich von -55°C bis zu +125°C messen kann.

Dieses Modul enthält einen NTC-Thermistor, der Temperaturen von -55°C bis +125°C messen kann. Der Thermistor verändert seinen Widerstand je nach Temperatur: Bei steigender Temperatur sinkt der Widerstand. Dieses Verhalten macht ihn ideal für die Überwachung von Schwellenwerten. Du kannst einen gewünschten Temperaturschwellenwert über ein Drehpotentiometer einstellen. Sobald die gemessene Temperatur diesen Schwellenwert überschreitet, gibt der Sensor ein digitales High-Signal aus. Der Vergleich zwischen eingestelltem und gemessenem Wert erfolgt durch einen eingebauten Komparator. Zusätzlich zeigt eine LED an, wenn der Sensor mit Spannung versorgt ist, und eine weitere LED leuchtet auf, wenn der Schwellenwert überschritten wird. Dieses Modul eignet sich hervorragend für Anwendungen, bei denen eine zuverlässige Temperaturüberwachung notwendig ist, wie z.B. in Heizungssteuerungen oder Klimaanlagen.

Benutzungshinweis

Dieser Sensor ist ideal für die Schwellenwertmessung geeignet. Das bedeutet, dass der Sensor ein digitales High-Signal abgibt, sobald ein am Drehpotentiometer vom Anwender eingestellter Schwellenwert überschritten wird. Hierbei ist zu beachten, dass das digitale Signal aus dem Vergleich des Wertes, welche am Drehpotentiometer eingestellt ist und dem gemessenen Wert am Sensor ist, welche dann vom auf dem Board verbauten LM393 Komparator verglichen werden. Dabei ist der eingestellte Wert des Drehpotentiometers der Schwellenwert, welcher dazu dient ein logisches High-Signal zu definieren.

Digitaler Ausgang: Wird der Schwellwert überschritten, so wird hier ein Signal ausgegeben

Analoger Ausgang: Direkter Messwert der Sensoreinheit

LED1: Zeigt an, dass der Sensor mit Spannung versorgt ist

LED2: Zeigt an, dass der Temperaturschwellenwert überschritten wurde

Funktionsweise des Sensors

Dieser Sensor besitzt auf seiner Platine zwei funktionelle Bestandteile: Die vordere Sensoreinheit, welche das Umfeld physikalisch misst und als analoges Signal auf die zweite Einheit, den Komparator, ausgibt. Der Komparator vergleicht den Messwert des Sensors mit der am Drehpotentiometer eingestelltem Wert und gibt bei Überschreitung des Wertes am Drehpotentiometer ein logisches High-Signal am digitalen Pin und der LED L1 aus.

Hierbei ist zu beachten: Das Signal ist invertiert. Wird ein hoher Wert gemessen, so resultiert dies in einem niedrigeren Spannungswert am analogen Ausgang.

Weihnachtsidee zum Bauteil

Weihnachtsidee: Der Eisblumen-Wächter

Wenn die Fensterscheibe kalt genug wird, wachsen Eisblumen. Der Thermistor-Fühler wacht auf der Fensterbank und meldet, sobald es frostig wird. Die Grenze stellst du direkt am Poti des Moduls ein.

Verdrahtung

Wie im Abschnitt zum Bauteil oben: Analoges Signal an A0, digitales Signal an Pin 3, +V an 5V, GND an GND.

Ablauf

Einmal pro Sekunde zeigt der Sketch die Spannung am Analogausgang und wie stark sie sich seit dem Start verändert hat. Wechselt der Digitalausgang, kommt die Meldung „Eisblumen-Gefahr“ oder „Entwarnung“.

Zum Einstellen legst du das Modul an die kalte Scheibe und drehst das Poti, bis die LED am Modul gerade umschaltet. Kommt die Meldung genau verkehrt herum, setze im Sketch FROST_BEI_HIGH auf false.

Code-Beispiel

Das Programm liest den aktuellen Spannungswert aus, der am analogen Ausgang gemessen werden kann, und gibt diesen auf der seriellen Schnittstelle aus. Zudem wird ebenfalls der Zustand des digitalen Pins in der Konsole ausgegeben. Dieser Zustand gibt an, ob der Grenzwert überschritten wurde.

Um das folgende Codebeispiel auf deinen Arduino zu laden, empfehlen wir die Verwendung der Arduino IDE. In der IDE kannst du den passenden Port und das richtige Board für dein Gerät auswählen.

Kopiere den unten stehenden Code in deine IDE. Um den Code auf deinen Arduino hochzuladen, klicke einfach auf den Upload-Button.

// Deklaration und Initialisierung der Eingang-Pins
int analog_input = A0; // Analoger Ausgang des Sensors
int digital_input = 3; // Digitaler Ausgang des Sensors

void setup () {
  pinMode(analog_input, INPUT);
  pinMode(digital_input, INPUT);
  Serial.begin(9600); // Serielle Ausgabe mit 9600 bps
  Serial.println("KY-028 Temperaturschwellenwertmessung ");
}

// Das Programm liest die aktuellen Werte der Eingang-Pins
// und gibt diese auf der seriellen Ausgabe aus
void loop () {
  float analog_value;
  int digital_value;

  //Aktuelle Werte werden ausgelesen, auf den Spannungswert konvertiert...
  analog_value = analogRead(analog_input) * (5.0 / 1023.0);
  digital_value = digitalRead(digital_input);

  //... und an dieser Stelle ausgegeben
  Serial.print("Analoger Spannungswert: ");
  Serial.print(analog_value, 4);
  Serial.print(" V, \t Grenzwert: ");

  if (digital_value == 1) {
      Serial.println("erreicht");
  }
  else {
      Serial.println("noch nicht erreicht");
  }
  Serial.println("----------------------------------------------------------------");
  delay(1000);
}

// Auflösung zu Türchen 3: Das Schneemann-Thermometer
// Verdrahtung wie im Artikel KY-001 (Signal an Pin 4)
// Bibliotheken: OneWire, DallasTemperature

#include <OneWire.h>
#include <DallasTemperature.h>

const char ART[] PROGMEM = R"ART(
         _===_
        ( o o )
       (   >   )
      (    :    )
     (     :     )
      `---------'
  Tuerchen 3: Das Schneemann-Thermometer
)ART";

#define KY001_Signal_PIN 4
OneWire oneWire(KY001_Signal_PIN);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  sensors.begin();
  Serial.println((const __FlashStringHelper*)ART);
}

void loop() {
  sensors.requestTemperatures();
  float t = sensors.getTempCByIndex(0);

  Serial.print(t, 1);
  Serial.print(" C: ");
  if (t <= 0.0) {
    Serial.println("Der Schneemann steht stabil. Perfektes Winterwetter!");
  } else if (t < 5.0) {
    Serial.println("Die Karottennase wird weich, der Schneemann schmilzt langsam.");
  } else {
    Serial.println("Nur noch eine Pfütze mit Hut und Kohlestücken ...");
  }
  delay(1000);
}
